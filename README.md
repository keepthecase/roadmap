# Keep The Case · roadmap

  The public board where [Keep The Case](https://switch.keepthecase.app) decides what gets built next.

  **Keep The Case** is a free collection manager for physical games. Your collection lives in a Google Sheet you own; the catalogue, the covers, the scores and the prices come to it. This repo holds no code — only the [Discussions](https://github.com/keepthecase/roadmap/discussions).

  ## How it works

  | Who | What |
  |---|---|
  | Anyone with a GitHub account | Votes for the ideas they want in [Ideas](https://github.com/keepthecase/roadmap/discussions/categories/ideas). One vote per person. Sort by **Top** to see what leads |
  | Supporters from the Boxed tier | Propose the ideas on Patreon and filter what reaches this board. Their votes count double (Boxed) or four times (Sealed), added by hand when deciding |
  | The Patreon polls | Settle the big calls, like which console arrives next. Patrons only |

  Every idea carries one label: `under review`, `planned`, `shipped` (with the announcement linked) or `declined` (with the reason in the thread).

  ## Want to propose something?

  [Support the project on Patreon](https://www.patreon.com/keepthecase) and post it there. What it costs to run this, what stays free and what each tier includes: [Why support the project](https://switch.keepthecase.app/supporters).

  Bugs and questions go to info@keepthecase.app, not here.

  Pégalo en Add file → Create new file, nombre README.md, y «Commit changes» directo a main. Los dos enlaces del sitio (/supporters, la vanity de Patreon) son los mismos que lleva el pie de la web.
